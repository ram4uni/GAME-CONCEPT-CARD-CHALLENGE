# Game Concept Card Challenge — Eight-Card Edition

This is the original eight-cards-per-deck Open Day challenge with five rounds.

## Flow
Welcome → pick one of eight cards in each of five rounds → reveal five selected cards → Are You Ready? → timer.

## Countdown
The **SET THE TIMER** button on the Are You Ready? screen opens the timer. Choose 10, 15, 20 or a custom number of minutes, then select START TIMER. Pause, resume and reset are available. It remains silent throughout the countdown and plays `timer-finish.wav` **once at 00:00**. The screen displays TIME’S UP and a presentation prompt. Reset or start a new challenge to reuse.

## Hosting on GitHub Pages
Upload all contents of this folder (including `CardImages`, `cards.js`, `game.js`, `style.css`, `index.html` and `timer-finish.wav`) to the root of your GitHub Pages repository. The ZIP intentionally excludes local `.git` history.

If sound does not play, check that the browser/tab is not muted and that the finish WAV was uploaded. Browsers may restrict audio until the page has received a user interaction; pressing START TIMER provides that interaction.
